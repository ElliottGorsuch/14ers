# Colorado 14er photo credits

Reviewed October 2, 2026. This collection contains licensed photographs, with one image association for every active route card. Peak overviews are reused across alternate routes; dedicated route-detail coverage is partial. North Eolus uses an Eolus massif context view; South Little Bear uses Little Bear context. These are explicitly labeled in the catalog.

Import `photo_manifest.json`: join its `routes` by `route_id`, resolve `hero_image_id` / `gallery_image_ids` against `photos`, and serve each relative `path`. Keep the attribution, source link and license visible on the site. Do not label a peak overview as a route photo.

Images keep their individual licenses. CC BY requires attribution; CC BY-SA also requires compatible licensing for image adaptations, and an indication of changes. Public-domain/CC0 works are credited for traceability. No source image was edited locally; resized previews were produced by Wikimedia. Existing source-file edits, where any, are described on the linked Commons page. Code licensing does not replace these image licenses. No 14ers.com or unlicensed trip-report photos are included.
